# Data files

- `*_experiment_*.mat` contains saved Simulink output structs used for the paper's settling-time and input-effort calculations. The `_full` files preserve the longer traces used for plotting.
- `RSHAC_real_condition.mat` contains the simulation trace paired with the real experiment.
- `RSHAC_real_swing_up.csv` is a headerless trace. The first five columns are cart position, cart velocity, pendulum angle, pendulum angular velocity, and control input. Firmware versions with timing output append elapsed milliseconds as column six.
- `goal_time_RSHAC.xlsx` is the summary table generated by `simulation/get_goal_time.m`.

The MATLAB scripts read inputs from this folder and write derived figures to the package's `figures/` folder.
