# Robustness outputs

The `.txt` and `.mat` files are the outputs of `run_experiments.m` with MATLAB R2022b, regenerated on 2026-09-29 from the scripts in this repository (LQR gain of Eq. (25), `analysis/lqr_gain.m`). The text outputs include numerical summaries; the MAT files preserve the corresponding result structures. Rerunning a script replaces its log files.

E3, E6, and E7 report RS-HAC, LQR, and FC-clip. E4 and E5 additionally report FC-fis and FC-lin sensitivity cases, which are not reported in the paper. Table 7 of the paper is taken from these logs.
